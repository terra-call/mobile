Integrate the Reolink E1 Pro camera into Terra Call. 
Here is the complete integration spec:

OVERVIEW:
The Reolink camera provides a secondary video feed during 
emergencies and can be viewed independently by the caregiver. 
It connects via the Reolink API over the local WiFi network 
or remotely via Reolink's cloud.

PHASE 1 — Care Recipient Camera Setup Screen:
Create a new screen in the Care Recipient settings called 
"Home Camera Setup" that allows the care recipient to:
1. Enter their Reolink camera IP address (local) or use 
   Reolink cloud login (email + password)
2. Enter Reolink username and password
3. Test the connection with a "Test Connection" button
4. Save the camera credentials to their Firestore user doc 
   under a new field: reolink: { ip, username, password, 
   cloudEnabled, connected }
5. Show connection status: Connected ✅ / Not Connected ❌
6. Camera consent must be granted before setup is allowed

PHASE 2 — Caregiver Dual-Feed View:
During an active emergency or when caregiver initiates camera:
1. Show two video feeds side by side (or stacked on mobile):
   - Feed 1: Twilio Video (care recipient phone camera) — 
     already working
   - Feed 2: Reolink camera stream
2. If Reolink is not configured, show placeholder: 
   "No home camera configured"
3. If Reolink is configured but offline, show: 
   "Home camera offline"
4. Label each feed clearly: "Phone Camera" and "Home Camera"

PHASE 3 — Reolink API Integration:
Use the Reolink HTTP API (not RTSP for now — use snapshot 
or MJPEG stream):
- Base URL: http://{ip}/api.cgi
- Auth: username + password in query params
- Stream endpoint: GET /api.cgi?cmd=Snap&channel=0&
  user={username}&password={password}
- For live stream use MJPEG: 
  http://{ip}/cgi-bin/api.cgi?cmd=Snap&channel=0&
  user={username}&password={password}
- Store credentials encrypted in Firestore
- Never log or expose credentials in console

FIRESTORE CHANGES:
Add to care recipient user document:
reolink: {
  ip: string,
  username: string, 
  password: string (encrypted),
  cloudEnabled: boolean,
  connected: boolean,
  lastConnected: timestamp
}

SECURITY:
- Auth gate on any server endpoint that proxies Reolink 
  requests
- Credentials never sent to client in plain text after 
  initial setup
- Use Replit server as proxy for Reolink requests to avoid 
  CORS issues

UI REQUIREMENTS:
- Camera setup screen matches Terra Call brand colors:
  Navy #183d7a, Green #6fda5d, Blue #51aafa
- Setup screen accessible from Care Recipient profile/
  settings
- Clear instructions for finding camera IP address
- "Need help finding your camera IP?" link/tooltip

IMPORTANT:
- Reolink camera is available on Family plan (optional) 
  and Pro plan (standard)
- Basic plan users should see an upgrade prompt instead 
  of the setup screen
- Do not break any existing Twilio Video functionality

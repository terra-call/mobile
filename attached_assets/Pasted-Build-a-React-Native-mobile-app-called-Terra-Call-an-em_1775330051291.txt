Build a React Native mobile app called Terra Call — an emergency caregiver monitoring app for iOS and Android.

## USER ROLES
Three roles:
- Care Receiver (elderly/vulnerable person being monitored)
- Caregiver (primary person monitoring)
- Family Member (secondary alerts only)

## CORE FEATURES TO BUILD

### Authentication
- Firebase Auth (email/password)
- Role selection on registration
- Caregiver can invite care receivers by email

### Care Receiver Screen
- Large "I'M OK" check-in button (one tap)
- Shows last check-in time
- Minimal UI — simple and easy for elderly users

### Caregiver Dashboard
- List of all care receivers with status (Checked In ✅, Missed ⚠️, Emergency 🚨)
- Real-time status updates via Firebase Firestore
- Last check-in time for each
- Real-time GPS location map for each care receiver
- EMERGENCY CALL button (red, prominent)
- Call 911 button

### Alert Logic
- If care receiver misses check-in by 30 minutes → push notification to caregiver
- Firebase Cloud Messaging for push notifications
- Twilio SMS backup alert to caregiver phone number

### Emergency Call Flow
- Caregiver taps EMERGENCY CALL
- Initiates VoIP call via Twilio Programmable Voice
- iOS: Uses CallKit for custom call screen on care receiver's phone
- Wyze camera feed auto-activates in caregiver view when call is initiated
- Two-way audio through app
- If care receiver doesn't answer — caregiver can still see and speak through Wyze camera

## TECH STACK
- Frontend: React Native (iOS + Android)
- Database: Firebase Firestore
- Auth: Firebase Auth
- Push Notifications: Firebase Cloud Messaging
- Calling + SMS: Twilio Programmable Voice + Twilio SMS
- Camera: Wyze API
- iOS Calling: CallKit

## PRIORITY ORDER
Build in this order:
1. Firebase auth + role-based registration
2. Care receiver check-in screen
3. Caregiver dashboard with real-time status
4. Push notifications + SMS alerts
5. Location tracking + map
6. Emergency call (Twilio + CallKit)
7. Wyze camera integration

## NOTES
- US launch only
- Wyze cameras only for MVP (no Ring)
- Keep care receiver UI extremely simple — large buttons, large text
- Caregiver UI is the power side — all emergency controls live here
- App should handle offline gracefully (show last known status)
